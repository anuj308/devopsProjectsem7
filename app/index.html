Deployment v2

Automated Docker Application Deployment on AWS Using Terraform and Ansible

By Anuj Kumar Sharma

This page is the application being deployed. Its version label lets a visitor tell which revision the server is serving.

Objective

Replace manual server setup with a process that can create a server, publish a page, update it, and remove the infrastructure when the demonstration ends.

Deployment workflow

  1. Package locally. Docker builds an image containing this page and Nginx, the web server.
  2. Create infrastructure. Terraform defines the AWS network, access rules, and EC2 virtual machine.
  3. Configure the server. Ansible connects over SSH, installs Docker, copies the source, and builds and starts the container.
  4. Verify and update. Open the EC2 address in a browser. After changing the version label, rerun Ansible and check the same address.

Expected outcome

The same webpage works locally and on EC2. A content update does not require a new server, and Terraform can remove the project infrastructure after the demonstration.
